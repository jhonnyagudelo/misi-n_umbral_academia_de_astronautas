# Guía de presentación · Misión Umbral

## Idea central

Un entrenamiento espacial para aprender a decidir: cuidar una tripulación exige distribuir recursos y aceptar costos. El jugador aprende haciendo, con un astronauta que se mueve, pistas narradas y resultados visibles.

## Recorrido sugerido de demostración

1. Abrir el enlace del README y explicar la meta: rescatar la base.
2. Mostrar una mejora del traje y su costo, y elegir tres.
3. Elegir Artemis normal. Mostrar el bloqueo de Apolo y comparar agua de llegada frente a tiempo de refugio.
4. Mostrar el despegue y un paso del viaje con el destino identificado.
5. En la base, conectar una batería y explicar por qué cuatro baterías no pueden alimentar seis estaciones simultáneamente.
6. Mostrar la diferencia entre reservas BASE y TRAJE, una salida y un punto de recarga.
7. Abrir AVATAR: una muestra viaja y otra queda en Tierra para comparar.
8. Explicar la alerta solar, el refugio y el cierre con preguntas educativas.

Se puede pausar para explicar sin consumir reservas. Una partida completa necesita más tiempo que una demostración breve; no presentar una demostración parcial como una misión completada.

## Qué está implementado

Preparación, dos dificultades con desbloqueo, vuelo ilustrado, hábitat de cuatro pisos, reparto de energía, salidas y reparaciones, AVATAR, cultivo, dos emergencias, recarga del traje, reintento, guardado local, narración y música independientes.

## Qué debe explicarse con honestidad

- Es un prototipo y un hábitat futuro simulado, no una nave certificada.
- Apollo/Orion se usan para comparar sistemas, no como misiones reales a esta base.
- Las cifras son reglas educativas; no predicen seguridad ni exposición humana.
- No se ha validado todavía la comprensión con niños de siete años.
- La comida y las baterías extra aún no aportan otro beneficio; agua extra sí.
- RTG, radio demorada, polvo/moho, compañeros transportables y DONKI histórico siguen pendientes.

## Evidencia disponible

131 pruebas de dominio, progreso, voz y contenido aprobadas; TypeScript y compilación correctos. Revisión de navegador en seis formatos y revisión independiente de las reglas recientes. Evidencia local de funcionamiento, no una certificación externa.
